\chapter{Выводы}
\label{chap:conclusion}

Наша реализация языкового сервера превосходит существующее решение за счёт
дополнительных функций, однако она требует доработки. Необходимо добавить такие
функции, как контекстно-зависимое автодополнение кода и поддержка
переименования. Кроме того, нужно реализовать инкрементальный парсинг, что
потребует разработки собственного фронтенда для компилятора Jasmin для
эффективной обработки небольших изменений в коде. Также будет полезна
возможность форматирования кода с настраиваемыми опциями для улучшения
читаемости.
